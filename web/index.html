Conversation AI

Checking OpenAI setup.

Everyday greetings and workspace requests work offline. Free-form conversation uses your own OpenAI API account, with separate usage charges.

  1. Install the optional OpenAI support: python3 -m pip install -r requirements-ai.txt
  2. Set OPENAI_API_KEY privately in the terminal environment. Never paste it into a chat or save it in this browser.
  3. Start your normal workspace with python3 app.py --enable-ai. Demo mode keeps OpenAI off.
