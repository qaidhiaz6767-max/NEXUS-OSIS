## Continuation in this branch

The later approved Home direction supersedes the November 7 five-card Home. Home now centers the existing liquid-glass orb on dark navy, keeps the quiet top bar and removes the permanent workspace cards, supporting copy, chat composer and footer. The demo disclosure remains visible in demo mode.

- Existing startup ordering, real readiness, reduced motion, retry and speech preferences remain.
- All seven backend workspace IDs and the five primary six-function workspace pages remain.
- Activate voice explicitly and say **“open OSIS workspace”** or **“open ATLAS workspace.”** Navigation uses the server's readable workspace list.
- Say **“go home”** or **“kembali ke beranda”** to return to the orb. This changes the view while preserving the current workspace's storage scope.
- **⌘ K** on Mac or **Ctrl K** opens text conversation on demand. The profile drawer also provides navigation. When speech recognition is absent, activating the orb opens text conversation.
- Microphone failures surface a visible error with retry and conversation access. Idle Home stays quiet; screen readers retain state announcements.
- Voice remains opt-in and stops on navigation. It does not restart merely because a destination page loads. Navigation does not call cloud AI, create chat/business records or approve anything.

No Python application logic, Core package, schema, provider, permission or approval API changed in this continuation.

git clone --branch recovery/orb-first-home-20261110 https://github.com/qaidhiaz6767-max/NEXUS-OSIS.git NEXUS-Recovered
cd NEXUS-Recovered
python3 app.py --demo
